What is P-and-p-editor?

It is a standalone retro-IDE and fantasy console for rapid prototyping, built on Godot 4. This is a tool for those who want to turn ideas into code faster than brewing a cup of coffee. No bloated menus, no loading screens — just you, your code, and the grid.

📦 What's inside the box?

Trinity Workspace

Instant switching between Code (F1), Sprites (F2), and Map (F3). Focus is your only currency.

Hybrid Sprite Atlas

Upper Zone (32x32) for heroes, Lower Zone (8x8) for environmental tiles and grids.

Live-Coding Pulse

Change your jump height or canvas color, hit F4 — the engine rewrites reality on the fly.

Micro-Cartridges

Your entire project—code, art, and map—packs into a tiny standalone binary .sav cartridge file.

🎮 Engine API Cheat Sheet ( _e )

Lightweight syntactic sugar layer wrapping native Godot 4 GDScript:

_e.pset(x, y, color)          # Leave a mark in VRAM layout
_e.sspr(sx, sy, x, y, w, h)   # Summon crisp pixels from the atlas canvas
_e.mget(tx, ty)               # Query the grid map layout array data
_e.sfx(freq, duration)        # Generate procedural square-wave resonance
_e.camera(x, y)               # Shift the world viewport rendering perspective

⚠ SECURITY WARNING: EXTERNAL CARTRIDGES

P&P Editor runs binary executable scripts from .sav structures. ONLY download and execute cartridges from creators you absolutely trust. Built-in "Forbidden Command Filter" protects system hooks, but sandbox vigilance is required.

Technical Specifications

Platform Stack: Windows / PC standalone binary wrapper.

Core Engine: Godot 4 architecture.

Color Space: Strictly limited palette (9 functional colors for extreme shape/movement art focus).

Footprint: Highly portable. Entire workspace, IDE, and projects pack into a few megabytes.
